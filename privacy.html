Data and account control

Privacy policy

Last updated: October 19, 2026

MP MultiChat is a native Windows OBS plugin maintained by MostlyPositive through mostlypositive-dev. It connects directly to Twitch and Google/YouTube. It does not operate an MP account service or a developer-hosted authentication or chat relay.

This policy describes the current 1.1 development implementation. Version 1.0 does not include the newer saved Activity history, viewer-card moderation, or offline public-subscriber monitoring features. Review this policy before connecting an account.

1. Data the plugin accesses

When you authorize a platform, the plugin receives OAuth access and refresh tokens, granted permissions, token-expiry information, and the connected channel's identifier and display name. You enter your own application's client ID and, when required for your Google Desktop client, its generated client secret locally in OBS. The plugin does not ask for or store your Google or Twitch account password.

Depending on available platform features and your settings, the plugin also processes:

  • Broadcast, channel, live-chat, event, and message identifiers.
  • Chat text, timestamps, viewer names and identifiers, public profile information, profile-image URLs, colors, badges, emotes, and channel-owner/moderator/member/subscriber roles where supplied.
  • Supported activity such as Twitch follows, subscriptions, gifts, Bits and raids; YouTube memberships, member milestones, gifts, Super Chats, Super Stickers and other supported livestream support events. These can include event text, quantities, membership details, amounts and currencies supplied by the platform—not payment-card or billing credentials.
  • Recent public YouTube subscriber records when subscriber monitoring is enabled. Private subscriptions are not made available, and snapshot detection may be delayed or incomplete.
  • The outgoing messages and supported moderation requests you initiate in OBS.

2. Why this data is used

Data is used to authenticate and restore the connected channel, receive and display combined chat and a separate Activity Feed, send your composed messages, load available viewer information and display assets, prevent duplicate events, recover connections, and carry out supported moderation actions after your confirmation.

YouTube access uses the https://www.googleapis.com/auth/youtube.force-ssl permission. Google describes that permission broadly; the implemented uses are channel identity, active-broadcast discovery, chat and activity receive/send, public-subscriber monitoring, public-profile lookup and supported user-initiated moderation. Twitch optional moderation features need additional permissions.

The plugin does not sell this data, use it for advertising, or send it to an AI service for model training. It has no developer-operated analytics or automatic chat/account-data upload service. Its data use is limited to the functions described here.

3. Local storage and retention

Settings, client IDs, and selected appearance controls are saved in your Windows user profile. OAuth tokens and a locally supplied Google Desktop-client secret are protected at rest with Windows Data Protection API (DPAPI), tied to the Windows security context. The plugin does not fall back to plaintext if protection fails.

Chat history and profile/image caches are bounded and held in memory, not saved as a chat archive by the plugin. They are discarded when OBS/the plugin process ends. Public profile images and emotes are downloaded from permitted platform image hosts; no developer image proxy is used.

In the current 1.1 development version, Save Activity Feed across OBS restarts is enabled by default. It saves a bounded DPAPI-protected local archive that can contain public actor/channel identities, event timestamps and text, membership/gift/amount metadata, and public image URLs. It does not store image bytes, credentials, or raw API responses in that archive. The default limit is 500 events, configurable from 100 to 5,000, with an additional serialized-data size limit.

The archive has no age-based automatic expiry: saved events remain until cleared, saving is disabled, the limit evicts them, or local data is removed. It may include more than one previously connected channel. Disconnecting an account or uninstalling the plugin does not by itself erase saved Activity history or appearance settings.

OBS retains its own diagnostic logs. MP MultiChat writes generic lifecycle/status messages and numeric failure information, not access tokens, refresh tokens, authorization codes, client secrets, or raw authentication payloads. OBS and other plugins have their own logging behavior. Avoid sharing unredacted logs.

4. Connections and sharing

OBS communicates with the selected platform's official authorization, API, chat/event and image services. Those services receive the network/request information needed to respond, and tokens are sent to the appropriate platform for authorized requests. User-selected profile or sign-in links open in your browser.

Messages you send to a platform are published through that platform and may be visible to its viewers. Choosing Both sends your composed message to both Twitch and YouTube; merely displaying received messages together does not repost viewers' messages across platforms. Confirmed moderation requests are sent to the selected platform and can change messages or viewer access there.

MostlyPositive does not automatically receive your account tokens, chat history or Activity archive. If you deliberately submit a support issue, screenshot or log, the information you submit is shared with that support channel and, for public GitHub issues, its readers. Do not submit private credentials or personal information.

Third-party services apply their own policies: Google Privacy Policy, Twitch Privacy Notice, and the YouTube Terms of Service. MP MultiChat uses YouTube API Services.

5. Disconnect, revoke access, and delete data

  • Stop local account access: Tools → MP MultiChat Settings → Accounts → Disconnect for the relevant platform removes its local token grant. For Google, the confirmation offers local-only removal or an attempt to revoke remotely. Local-only removal does not revoke access at Google.
  • Revoke Google access directly: remove the application's connection in your Google Account security permissions. Google revocation can affect other clients in the same Cloud project. You can also manage access through Twitch Connections for Twitch.
  • Clear saved events: Settings → Appearance → Activity Feed → Clear activity history clears displayed and saved Activity Feed entries after confirmation. Disabling Save Activity Feed across OBS restarts and applying appearance deletes the saved archive while leaving the current in-memory feed visible.
  • Remove the separately stored Google client secret: Accounts → Forget Google app secret removes that value, not the separate account grant or Activity history. Disconnect and clear history separately when desired.
  • Full local reset: close OBS and remove only MP MultiChat's application-data folder, normally %LOCALAPPDATA%\MostlyPositive\MP MultiChat. This removes its saved credentials, settings and Activity archive, not content retained by platforms, separate OBS logs, or system backups. Never delete the whole LocalAppData or OBS directory.

Windows permission/storage errors can prevent a local removal; the plugin reports an error rather than claiming success. Removing local records does not delete messages or events retained on Twitch or YouTube. Manage those through the platform's supported controls.

6. This informational website

This is a static GitHub Pages website. It has no Google/Twitch login form, application cookies, browser-storage features, embedded platform widgets, analytics scripts, or access to your OBS credentials. The pages use locally hosted styling and images.

GitHub provides the hosting and processes ordinary connection/request information, including visitor IP addresses for security, under the GitHub Privacy Statement. Following an external link contacts that external service under its policies.

7. Questions and policy updates

For questions or complaints about these data practices, open an issue with mostlypositive-dev in the website repository. This is a public channel: describe your concern without including tokens, passwords, client secrets, private account data, or unredacted logs.

This page will be updated when the described practices change, with the update date shown above. Platform policies and account controls remain separate from this policy.
